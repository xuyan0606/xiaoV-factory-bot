### 1.2 感知层 — 数据采集架构

```
                    +------------------+
                    |   感知层网关集群   |
                    | (Edge Gateway)   |
                    +--------+---------+
                             |
           +-----------------+------------------+
           |                 |                  |
    +------v------+  +------v------+  +-------v------+
    | MQTT Broker |  |  OPC-UA    |  |  Modbus      |

           |                 |                 |

    +-------------+  +-------------+  +--------------+
```

**网关选型**: EMQX (MQTT Broker) 端口 1883, WebSocket 端口 8083
**数据采集策略**:
- 高频: 包装线数据 (100ms) — 直接MQTT上报
- 中频: 发酵罐工艺参数 (1s) — Modbus轮询
- 低频: 环境温湿度 (30s) — Modbus轮询

### 1.3 数据层 — 存储架构

| 数据类型 | 存储引擎 | 保留策略 | 用途 |

| 关系数据 | MySQL/PostgreSQL | 永久 | 设备元数据、批次信息、工单 |

3. **物料孪生模型**: 批次物料追踪、物料平衡计算
4. **产线孪生模型**: 整线联动的仿真模型

## 3. 实时数据同步机制

### 3.1 架构设计

```
 +-------------+         +------------+         +-------------+
 | 设备传感器   |  MQTT  |  EMQX      |  WS    |  前端浏览器  |
 | (MQTT Client)|------->| (Broker)   |------->| (Three.js)  |
 +-------------+         +-----+------+         +-------------+
                               |
                               | Kafka Bridge
                               v
                         +-----------+
                         | Kafka     |
                         | Event Bus |
                         +-----+-----+
                               |
                    +----------+----------+
                    |                     |
              +-----v-----+       +-------v------+
              | TDengine   |       | 后端服务      |
              | (时序存储)  |       | (数据处理)     |
              +-----------+       +--------------+
```

### 3.2 WebSocket 连接管理

```python
# 连接生命周期
1. CONNECTING   -- 客户端发起WebSocket连接
2. CONNECTED    -- 握手成功，认证通过
3. SUBSCRIBED   -- 订阅设备topic列表
4. STREAMING    -- 实时接收数据推送
5. RECONNECTING -- 断线重连 (指数退避)
6. DISCONNECTED -- 连接关闭
```

### 3.3 数据流协议

**上行 (设备→平台)**:
```
Topic:   dt/{plant}/{workshop}/{deviceId}/telemetry
Payload: {
  "ts": "2026-04-27T19:00:00.000Z",
  "values": {"temperature": 37.2, "pressure": 0.15},
  "quality": 100
}
QoS: 1
```

**下行 (平台→设备)**:
```
Topic:   dt/{plant}/{workshop}/{deviceId}/command
Payload: {
  "cmd": "set_temp",
  "params": {"target": 38.0},
  "timestamp": "2026-04-27T19:00:00.000Z",
  "expiry": 30000
}
QoS: 2
```

### 3.4 数据同步策略

| 策略 | 适用场景 | 延迟要求 | 实现方式 |
|------|---------|---------|---------|
| 实时推送 | 工艺参数监控 | <200ms | MQTT → WS 直接转发 |
| 批量同步 | 历史数据加载 | <5s | Kafka消费批量写入 |
| 快照同步 | 页面初始化 | <1s | Redis缓存设备快照 |
| 差量同步 | 模型更新 | <2s | 只推送变更字段 |

```
+-----------+          +--------------+
     |                       |
     | Modbus Polling        | WebSocket Push
     v                       v
+-----------+          +--------------+
| 数据采集器 |--------->| 实时数据库   |
| (边缘网关) |  MQTT   | (TDengine)  |
+-----------+          +--------------+
```

### 4.2 映射引擎实现

```
Input:  {deviceId, timestamp, values:{k1:v1, k2:v2, ...}}
        |
        v
+-----------------------+
| 1. 协议解析层          |
|    - MQTT -> JSON     |
|    - Modbus -> 寄存器  |
|    - OPC-UA -> 变量   |
+-----------+----------+
            |
            v
+-----------------------+
| 2. 字段映射层          |
|    Modbus寄存器地址    |
|    -> 孪生体属性路径   |
|    e.g. 0x0001 ->     |
|    twin.telemetry.temp|
+-----------+----------+
            |
            v
+-----------------------+
| 3. 数据转换层          |
|    - 量程换算          |
|    - 单位转换          |
|    - 阈值计算          |
|    - 质量标记          |
+-----------+----------+
            |
            v
+-----------------------+
| 4. 孪生体更新层        |
|    - 更新属性值        |
|    - 触发事件检查      |
|    - 状态机转换        |
|    - 写入时序库        |
+-----------+----------+
            |
            v
Output: {twinId, timestamp, updatedFields, events[]}
```

### 5.2 发酵动力学模型 (Monod方程)

```
μ = μ_max * [S] / (Ks + [S]) * Ki / (Ki + [I])

μ       — 比生长速率 (h⁻¹)
μ_max   — 最大比生长速率 (h⁻¹)
[S]     — 底物浓度 (g/L)
Ks      — 半饱和常数 (g/L)
[I]     — 抑制物浓度 (g/L)
Ki      — 抑制常数 (g/L)

温度修正:
μ_max(T) = μ_max_opt * exp(-((T - T_opt)² / (2 * σ²)))
```

### 5.3 仿真场景类型

| 场景类型 | 描述 | 用途 |
|---------|------|------|
| 工艺参数优化 | 调整温度/pH/DO等参数 | 最优发酵条件探索 |
| 瓶颈分析 | 识别产线瓶颈设备 | 产能提升规划 |
| 故障模拟 | 模拟设备故障影响 | 应急预案验证 |
| 排产验证 | 验证生产计划可行性 | 排产方案评估 |
| 能耗优化 | 分析设备能耗模式 | 节能改造方案 |

### 5.4 推演流程

```
1. 创建场景
   - 选择基准产线配置
   - 设定仿真时长
   
2. 设置参数
   - 修改工艺参数 (温度/pH/转速)
   - 设定设备可用性
   - 配置物料投加计划
   
3. 执行仿真
   - 引擎按时间步进计算
   - 实时输出指标变化
   - 记录所有事件
   
4. 分析结果
   - 对比基准方案
   - 查看KPIs变化
   - 导出仿真报告
   
5. 应用决策
   - 将最优参数下发到产线
   - 调整生产计划
```

## 6. KPIs / 指标体系

### 6.1 设备层级 KPI

| KPI | 公式 | 目标值 | 采集频率 |
|-----|------|-------|---------|
| 设备综合效率 (OEE) | 可用率 × 性能率 × 合格率 | ≥85% | 实时/班次 |
| 设备可用率 | 运行时间 / 计划生产时间 | ≥95% | 实时 |
| 平均故障间隔 (MTBF) | 总运行时间 / 故障次数 | ≥720h | 按事件 |
| 平均修复时间 (MTTR) | 故障总时间 / 故障次数 | ≤2h | 按事件 |
| 温度偏差率 | |ΔT| / 目标值 × 100% | ≤2% | 每批次 |

### 6.2 产线层级 KPI

| KPI | 公式 | 目标值 |
|-----|------|-------|
| 产量达成率 | 实际产量 / 计划产量 × 100% | ≥95% |
| 一次合格率 | 一次通过批次 / 总批次 × 100% | ≥98% |
| 计划达成率 | 按时完成批次 / 总批次 × 100% | ≥90% |
| 转换效率 | 产出量 / 投入原料量 × 100% | ≥85% |
| 能耗密度 | 总能耗 / 产出量 (kWh/kg) | ≤2.5 |

### 6.3 数字孪生平台 KPI

| KPI | 指标 | 目标值 |
|-----|------|-------|
| 数据采集延迟 | 从设备到孪生体更新 | ≤500ms (P99) |
| 数据完整性 | 成功采集率 | ≥99.9% |
| 孪生体刷新率 | 每秒钟孪生体更新次数 | ≥10次/s |
| 3D渲染帧率 | 浏览器端渲染 | ≥30fps |
| 仿真推演速度 | 实时比 vs 推演速度 | ≥10× 实时 |
| 系统可用性 | 平台整体可用性 | ≥99.9% |
